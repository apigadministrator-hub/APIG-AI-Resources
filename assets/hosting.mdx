This page records every hosting environment APIG uses. Each entry identifies the provider, hosted resource, public URL, and operational status.

## Record Fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for the hosting asset (e.g., APIG-ASSET-HOST-001) |
| Provider | Hosting service or platform vendor |
| Hosted Resource | Name of the hosted application, site, or service |
| Public URL | Accessible URL for the hosted resource |
| Purpose | Business or operational reason for the environment |
| Status | Current operational state (Active, Inactive, Deprecated, etc.) |
| Plan/Tier | Subscription or service level |
| Administrator | Responsible party or role |
| Notes | Additional context, integrations, or caveats |
