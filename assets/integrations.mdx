Integrations connect APIG to external services, enabling data exchange, automation, and extended functionality across your stack. Each integration entry records the connected service, its purpose, how it authenticates, and its current operational status. Register every integration before configuring it in a workflow or connecting it to a form or webhook.

## Record fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for this integration record. |
| Integration Name | Human-readable name of the integration. |
| Service | Name of the third-party service or platform. |
| Purpose | What this integration does within APIG. |
| Auth Method | How APIG authenticates with the service (API key, OAuth, token, etc.). |
| Status | Current state: Active, Inactive, Deprecated, or Pending. |
| Notes | Additional context, links, or caveats. |
