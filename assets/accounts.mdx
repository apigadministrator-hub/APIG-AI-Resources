This page records every external platform account associated with APIG operations. Credentials are never stored here.

## Account Record Fields

| Field | Description |
| --- | --- |
| Asset ID | Unique APIG asset identifier (e.g., APIG-ASSET-ACCT-001). |
| Service | External platform or provider name. |
| Account Name/Handle | Username, organization name, or handle on the platform. |
| Purpose | Brief description of what the account is used for. |
| Status | Current asset status (Active, Inactive, Pending, Unknown, Deprecated, Archived). |
| URL | Direct link to the account or organization page, if applicable. |
| Administrator | Person or team responsible for the account. |
| Notes | Additional operational details, plan tier, or restrictions. |
| Credentials | Never stored in this registry. |
