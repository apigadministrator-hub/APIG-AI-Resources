This page records APIG brand assets and their designated usage contexts. The two primary logos serve distinct identities and must not be substituted for one another per APIG-37.

## Record Fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for the brand asset (e.g., APIG-ASSET-BRAND-001) |
| Asset Name | Descriptive name of the brand asset |
| File Name | Exact filename including extension |
| Source URL | Direct link to the canonical file |
| Usage Context | Where and how the asset may be used |
| Status | Current state (Active, Deprecated, Superseded, etc.) |
