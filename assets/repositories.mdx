This page records every repository associated with APIG operations. Repositories hold specifications, code, deployment records, and other persistent project resources.

## Record Fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for the repository asset (e.g., APIG-ASSET-REPO-001) |
| Repository Name | Name of the repository as shown on the host platform |
| Host | Platform hosting the repository (e.g., GitHub, GitLab) |
| Owner | Organization or user account that owns the repository |
| URL | Direct link to the repository page |
| Visibility | Public or Private |
| Purpose | What the repository contains and how it is used |
| Primary Branch | Default branch for development and deployment |
| Status | Current state (Active, Archived, Deprecated, etc.) |
| Notes | Additional context, access rules, or integration details |
