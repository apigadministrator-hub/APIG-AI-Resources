The integration registry documents every connection between APIG systems and external platforms. Before integrating a new service, check this registry to determine whether an existing integration already covers the need.

## Integration record fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for this integration asset |
| Name | Human-readable name for the integration |
| Provider | The external service or platform |
| Integration Type | API, OAuth, Webhook, or Service Connector |
| Purpose | What APIG uses this integration for |
| Endpoint or Base URL | The public API endpoint or base URL |
| Authentication Method | Type only (for example, API Key, OAuth 2.0, Webhook Secret) |
| Connected Assets | Related APIG asset IDs |
| Status | Active, Inactive, Pending, or Archived |
