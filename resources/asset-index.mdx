The master asset index is the single authoritative reference for every operational asset in the APIG project. AI agents and administrators consult this index before creating any new asset. Every asset has a persistent ID, a status, and a record of its relationships to other assets.

<Warning>
  This index never contains passwords, API keys, tokens, or authentication secrets. Each record notes only that a credential is required and where to obtain it securely.
</Warning>

## Asset ID Format

Assets use a structured persistent ID:

```text
APIG-ASSET-[TYPE]-[NUMBER]
```

Examples:

```text
APIG-ASSET-REPO-001    → Repository
APIG-ASSET-ACCT-001    → Account
APIG-ASSET-DOMAIN-001  → Domain
APIG-ASSET-HOST-001    → Hosting service
APIG-ASSET-BRAND-001   → Brand asset (logo, image, media)
APIG-ASSET-FORM-001    → Form
APIG-ASSET-HOOK-001    → Webhook
APIG-ASSET-SCRIPT-001  → Script or automation
APIG-ASSET-WF-001      → Workflow
APIG-ASSET-INT-001     → Integration
```

## Asset Status Legend

| Status | Meaning |
| --- | --- |
| **Active** | In current use |
| **Inactive** | Exists but not currently used |
| **Pending Setup** | Planned or partially configured |
| **Retired** | No longer in use; record preserved for history |
| **Unknown** | Existence or status unverified |
