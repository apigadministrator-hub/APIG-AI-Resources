The domain registry tracks every domain name owned or operated by APIG. Domain ownership is separate from hosting. A domain may be registered with one provider while pointing to infrastructure on another.

## Domain record fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for this domain asset |
| Domain Name | The registered domain name |
| Registrar | Where the domain was purchased |
| DNS Host | The service managing DNS records |
| Primary Use | What APIG uses this domain for |
| Connected Hosting Asset | The hosting asset this domain points to |
| SSL Status | Whether SSL/TLS is configured |
| Expiration Date | When the domain registration expires |
| Status | Active, Pending, Expired, or Archived |
| Notes | Additional context |
