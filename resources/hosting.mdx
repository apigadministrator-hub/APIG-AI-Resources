The hosting registry tracks every service that hosts APIG content, applications, or data. This includes the documentation site, any future website hosting, and any database or application infrastructure.

## Hosting record fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for this hosting asset |
| Provider | The hosting service provider |
| Plan/Tier | The subscription plan or tier |
| Purpose | What APIG uses this hosting for |
| Connected Domain(s) | Any domains pointing to this hosting |
| Connected Repo(s) | Repositories deployed to this hosting |
| Deployed Application | The live application or site URL |
| Credential Location | Where to find access credentials |
| Status | Active, Inactive, Pending, or Archived |
| Last Verified | Date this record was last confirmed |
