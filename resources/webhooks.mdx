The webhook registry documents every webhook endpoint used by APIG. Webhooks are typically the bridge between a user-facing form or external event and an internal processing script or workflow.

## Webhook record fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for this webhook asset |
| Name | Human-readable name for the webhook |
| Source Asset | The asset that triggers this webhook |
| Trigger Event | The event that fires the webhook (for example, form submission) |
| Destination Endpoint | Public endpoint reference only |
| Connected Script or Workflow Asset | The asset that processes the webhook payload |
| Status | Active, Inactive, Pending, or Archived |
| Last Tested | Date the webhook was last verified to work |
