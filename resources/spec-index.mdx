The APIG specification library defines how the system is built, how it operates, and what rules govern each component. Every significant architectural, operational, and procedural decision is documented as a numbered specification. This index provides a reference to the full library.

<Tip>
  The authoritative specification files are maintained in the APIG-AI-Resources GitHub repository under /Specifications. This index is a navigation reference, not a substitute for reading the specification.
</Tip>
