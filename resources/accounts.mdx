The account registry documents every service account, platform subscription, and organizational account used by APIG. It identifies what each account does, who controls it, and where its credentials are stored. No credentials, passwords, API keys, or tokens appear in this registry.

<Warning>
  Never store passwords, API keys, tokens, or any other secrets in this registry. Record only the location where the credential is kept (for example, a secure credential store or password manager).
</Warning>

## Asset record template

Use the following template when adding a new account to this registry.

```text
Asset ID:           APIG-ASSET-ACCT-###
Name:               <account or service name>
Type:               <account type>
Provider/Platform:  <provider name>
Owner:              <owner or responsible party>
Login/Username:     <identifier only — no password>
Purpose:            <what this account is used for>
URL:                <service URL>
Status:             <Active / Inactive / Unknown / To Be Verified>
Credential Location: <where to find the secret — not the secret itself>
Connected Assets:   <related asset IDs>
Last Verified:      <date>
Notes:              <additional context>
```
