The scripts registry documents every automation script deployed to an external platform on behalf of APIG. Scripts are distinct assets from the platforms they run on. A Google Apps Script is deployed to a specific spreadsheet or container, and both the script and its deployment context are tracked here.

## Script record fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for this script asset |
| Name | The script name or title |
| Platform | Where the script runs (Google Apps Script, Zapier, etc.) |
| Deployment Location | The specific spreadsheet, project, or container it is deployed to |
| Version/Last Updated | Version number or last update date |
| Purpose | What this script does |
| Connected Assets | Related asset IDs (webhook, form, workflow) |
| Deployment Record Reference | Link or ID to the deployment record |
| Status | Active, Inactive, Pending, or Archived |
