The repository registry documents every code or content repository used by APIG. AI agents must consult this registry before creating new repositories or assuming a repository does not exist.

## Repository record fields

| Field | Description |
| --- | --- |
| Asset ID | Unique identifier for this repository asset |
| Name | The repository name |
| Platform | Where the repository is hosted (GitHub, GitLab, etc.) |
| Owner/Org | The organization or user that owns the repository |
| URL | The repository web address |
| Visibility | Public or Private |
| Primary Purpose | What this repository contains or is used for |
| Branch Notes | Key branch information or conventions |
| Connected Assets | Related asset IDs (accounts, hosting, etc.) |
| Status | Active, Archived, or Pending |
